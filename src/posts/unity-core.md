## 第一章：GameObject 与 Component 的关系（Unity 的核心设计思想）

### 1.1 GameObject 是什么？

**GameObject 是 Unity 场景中的一切实体的"容器"**。\
场景中的人物、敌人、子弹、摄像机、UI 元素，本质上都是 GameObject。

> GameObject 本身几乎没有功能，功能来自于它所挂载的 Component。

可以理解为：

-   GameObject：一个"空壳"或"主体"
-   Component：赋予主体能力的"模块"

Unity 使用的是 **组合（Composition）而不是继承（Inheritance）**。

------------------------------------------------------------------------

### 1.2 Component 是什么？

**Component 是附加在 GameObject 上的功能模块**。

例如：

  Component                功能
  ------------------------ --------------------
  Transform                位置 / 旋转 / 缩放
  Renderer                 渲染
  Collider                 碰撞
  Rigidbody                物理
  Script (MonoBehaviour)   逻辑

一个 GameObject 可以挂载：

-   多个 Component
-   同类型 Component（部分允许）

------------------------------------------------------------------------

### 1.3 MonoBehaviour 与 Component 的关系

继承关系：

    Object
     └── Component
          └── Behaviour
               └── MonoBehaviour

**结论：** - MonoBehaviour 本质上是一个 Component - 所有脚本都必须继承
MonoBehaviour 才能挂在 GameObject 上

## 第二章：MonoBehaviour 生命周期（必须掌握）

生命周期决定了：

-   代码什么时候执行
-   代码写在哪个函数里

------------------------------------------------------------------------

### 2.1 生命周期执行顺序（常见）

    Awake
    ↓
    OnEnable
    ↓
    Start
    ↓
    Update / FixedUpdate / LateUpdate（循环）
    ↓
    OnDisable
    ↓
    OnDestroy

------------------------------------------------------------------------

### 2.2 各生命周期详解

#### Awake()

-   **调用时机**：脚本实例被加载时（最早）
-   **特点**：
    -   不依赖 GameObject 是否激活
    -   场景加载阶段就会执行

**适合做的事：** - 变量初始化 - GetComponent 缓存 - 单例初始化

------------------------------------------------------------------------

#### OnEnable()

-   GameObject 或 Component 被启用时调用
-   **可能被多次调用**

------------------------------------------------------------------------

#### Start()

-   **调用一次**
-   在第一次 Update 之前
-   依赖 GameObject 为 active

**与 Awake 的区别：** - Awake：用于"准备资源" -
Start：用于"开始使用资源"

------------------------------------------------------------------------

#### Update()

-   每一帧执行一次
-   执行频率：**不固定**（与帧率有关）

**适合做的事：** - 输入检测 - 非物理逻辑 - UI 更新

------------------------------------------------------------------------

#### FixedUpdate()

-   固定时间间隔执行（默认 0.02 秒）
-   与帧率无关

**只用于：** - 物理计算 - Rigidbody 操作

------------------------------------------------------------------------

#### LateUpdate()

-   在 Update 之后执行
-   常用于：
    -   摄像机跟随
    -   修正位置

------------------------------------------------------------------------

#### OnDisable()

-   对象被禁用时调用

------------------------------------------------------------------------

## 第四章：Component 类与 GetComponent（重点）

### 4.1 Component 的本质

-   所有功能模块的基类
-   MonoBehaviour 继承自 Component

------------------------------------------------------------------------

### 4.2 GetComponent 的作用

**访问同一 GameObject 上的其他组件**

    SpriteRenderer sr = GetComponent<SpriteRenderer>();

------------------------------------------------------------------------

### 4.3 为什么不要在 Update 里用？

原因：

1.  GetComponent 是反射查找
2.  性能开销大
3.  每帧调用会造成 GC 压力

**正确做法：**

    private SpriteRenderer sr;

    void Awake()
    {
        sr = GetComponent<SpriteRenderer>();
    }

### 7.2 Time.fixedDeltaTime

-   FixedUpdate 的时间间隔
-   只用于物理

------------------------------------------------------------------------

### 7.3 如何每秒执行一次代码？

    float timer = 0f;

    void Update()
    {
        timer += Time.deltaTime;
        if (timer >= 1f)
        {
            timer = 0f;
            Debug.Log("每秒执行一次");
        }
    }

## 第八章：Input 输入系统

### 8.1 为什么只能在 Update 里处理 Input？

原因：

1.  Input 状态是**逐帧刷新**
2.  FixedUpdate 可能一帧执行多次或不执行
3.  会导致输入丢失或重复

------------------------------------------------------------------------

### 8.2 常用输入方法

  方法                 触发时机
  -------------------- --------------
  GetKeyDown           按下瞬间
  GetKey               按住
  GetKeyUp             松开
  GetMouseButtonDown   鼠标按下瞬间

------------------------------------------------------------------------

### 8.3 示例

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
        {
            Debug.Log("Jump");
        }
    }
