# 内容维护

## Markdown文章

在src/posts新增稳定文件名，文件名即slug，已有URL不要随改标题而变更。

```yaml
---
title: 文章标题
date: '2026-11-17'
category: 课程笔记
summary: 简短说明本文讲什么。
cover: /logo.png
---
```

title、date、category必填；summary建议填写，cover可选且本地路径需存在。frontmatter必须在文件开头。公式使用行内 `$...$` 和独立段落 `$$...$$`；显示公式内部避免空段。代码块注明语言，标题形成清晰层级。

新增后运行content:check并检查生成差异。不要手工修改content.generated.json；不要把本机盘符或原书绝对路径作为网页资源URL。

## PDF文章与替换

1. 将发布用文件放入public/pdfs，文件名用稳定英文slug。
2. 在src/data/pdfPosts.ts维护slug、title、date、category、summary、cover、pdfUrl。
3. 同slug可配Markdown正文，形成双格式文章。
4. 更新同主题PDF时保留原URL，调整日期与摘要以反映新版内容。
5. 核对来源、总页数、关键公式和文件哈希；在浏览器检查中文、英文、数字、公式和图。
6. build重新生成索引；上线后比较生产文件哈希与本地文件。

scripts/copy-pdfs.ts包含本机历史来源路径，是人工维护工具，不是课程新版的权威来源；不能无差别执行它覆盖已验收讲义。

## 数学建模原书版

共17讲，独立PDF合计134页。保留 `math-modeling-*` 原文章及文件URL。课堂PPTX决定主题范围，《李宏毅深度学习教程》1.2.4决定主要知识解释和公式依据。

标注区分：原书引用、解释性补全、课件补充、原书排印/表述修正。正文印刷页与PDF物理页不能混用；本版本正文物理页等于印刷页加1。自拟算例不能写成原书实验结果。Prompt、RAG、Agent等原书未覆盖内容不能伪造书籍出处。

详稿应包含概念、符号与维度、条件、推导、可复算例子、易错点及带答案自测。完整流程是全局阅读、按课堂范围映射、分段整理、独立内容核验、编译、PDF可视检查和网站阅读器检查。

本机生成源与核验材料位于 `artifacts/leedl-book-notes/`，已被git忽略，不会随全新克隆取得；需要再生成时先取得用户提供的原书和课件。部署站点只依赖public中的发布PDF，不依赖本机原书或生成工具。

原书署名：王琦、杨毅远、江季，Datawhale，《李宏毅深度学习教程》1.2.4，2025-06-13。原书声明CC BY-NC-SA 4.0，派生学习资料保留对应署名与许可；该声明不等于整个站点代码或所有课件均使用相同许可。

## 收藏和素材

收藏数据在src/data对应文件，封面位于public的分类目录。保留已有评价与真实条目，不编造作者经历或当前游玩状态。同步脚本只在需要时手动运行，密钥留在.env.local；优化图片会改写文件，应先看git差异。不要批量删除旧封面后再尝试下载。

参考站资源只供研究，不把其壁纸、音乐或模型复制为本站通用资产。已有背景属于用户指定保留素材，继续维护其原文件。
