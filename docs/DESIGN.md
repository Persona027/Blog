# 设计规范

## 已确认的方向

保持Persona自己的信息结构与功能，只借鉴参考站的审美和设计方法。首页介绍、课程入口、最近笔记、分类侧栏，以及文章、收藏、关于页面继续保留。

参考项目：https://github.com/TrAveller7150/playlist 。学习其内容主导视觉、封面与阅读节奏分工、低饱和配色、个人收藏表达和移动端细节；不复制美术、音乐、私人文案、模型或页面结构。项目内frontend-design skill是指导资料，用户要求优先。

## 背景与色彩

原项目背景必须保留：`public/background.png`。App中的aria-hidden固定背景层配合CSS cover居中显示，65%深色遮罩控制对比度；背景不拦截鼠标。不要把全站背景误写成仅首页头图，也不要为配色统一换成纯色。

| 变量 | 值 | 用途 |
|---|---|---|
| --bg | #191821 | 背景底色 |
| --surface | #22212c | 面板 |
| --raised | #2d2b39 | 选中和抬高层 |
| --ink | #eeebf2 | 正文 |
| --muted | #b0aab9 | 次要说明 |
| --accent | #c0b2dc | 链接、焦点与强调 |
| --line | #3b3749 | 分隔线 |

Markdown正文另有88%深色底，避免复杂背景影响长文。PDF画布维持原文白纸，不能通过混合模式或反色影响公式和图片。

## 排版与组件

中文标题用现有Mincho/宋体系衬线回退，正文使用系统无衬线。字体栈只引用浏览器已有字体，不为截图读取或复制系统盘字体。首页英文标题使用Georgia。替换字体先检查中文、标点、数字和公式混排。

首页用头像和实际收藏封面建立个人感；文案直接说明内容，不写泛化励志口号。面板边框、圆角和阴影依层级区分，不把所有内容做成同样卡片。收藏入口保留原分类，实际作品封面比通用装饰更重要。

不要为了“日系”强行加日文标签、樱花、播放控件或无来源插画。没有音源或使用需求时不新增播放器，没有真实物件时不新增3D展示。

## 验收

检查桌面和手机的首页、列表、收藏、关于与长文。无横向溢出、焦点可见、导航可触控；背景上文字清楚，封面不过度裁切。查看截图而不是只读CSS。尊重减少动态效果偏好，避免抢滚轮和逐卡片自动入场。

颜色和布局集中维护src/index.css；已有收藏/PDF组件仍有局部Tailwind颜色，后续调整需逐组件核对，不能假定只改变量就全站一致。
